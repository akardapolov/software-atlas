# Java Cheat Sheets

Quick-reference sheets that condense the language and its core standard-library
APIs into compact, printable pages. Each sheet is a single file with a table of
contents: one topic per section, with a short explanation and a practice idea
for every construct it covers.

| Part        | Focus                      | Topics                                                                                                                                                                                   | Page                     |
|-------------|----------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------|
| **Part I**  | Language basics            | Compilation and running, variables and types, operators, strings, conditionals, loops, arrays, methods, OOP basics, console input/output                                                 | [part-i.md](part-i.md)   |
| **Part II** | OOP in depth and core APIs | Inheritance, polymorphism and abstraction, encapsulation, exceptions, collections, generics, lambdas and Stream API, functional interfaces, files and I/O, multithreading, useful extras | [part-ii.md](part-ii.md) |

For deep dives into individual platform features (generics, streams, virtual
threads, FFM API, and others), see the numbered chapters on the
[Java main page](../index.md).
